## Public GitHub rule

The public package contains only the six redistributable source METs plus the MZand-generated consensus. The user-supplied eXtreme Gammon MET is excluded from the public package and appears only in the private benchmark package.

Target repository: `mzandstudio-svg/mzand-xg-runner-public`.
Suggested repository path: `met/mzand-consensus-v1/`.

Each packaged table carries a prefixed MZand integrity record containing its table name, Match Point, original SHA-256, packaging scope, and repository target. Original copyright and permission notices remain below that record.
